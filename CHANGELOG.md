# Changelog

## 0.2.1

- Updated the package contact email.

## 0.2.0

- Operations are now grouped under PrismCrawl resources: **Web Search** (Search Google), **Place** (Search Google Maps), and **Review** (Get Google Maps Reviews). Workflows built with 0.1.0 need the resource and operation re-selected.
- Testing the credential now runs one Google search, which uses 1 credit.
- Google Domain is now a text field.
- Added the MIT license and example workflows to the README.

## 0.1.0

Initial release.

- PrismCrawl API credential
- Google: Search
- Google Maps: Search and Get Reviews, with optional automatic pagination capped by Max Pages
